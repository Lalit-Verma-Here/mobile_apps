# Exercise 7: Android Widget

## Overview
This is the 7th exercise for the mobile application class. This android application demonstrates the implementation of a home screen Widget.

Main Files:
- [AndroidManifest.xml](./app/src/main/AndroidManifest.xml)
- [MyWidget.java](./app/src/main/java/com/example/exp7/MyWidget.java)
- [MainActivity.java](./app/src/main/java/com/example/exp7/MainActivity.java)
- [widget_layout.xml](./app/src/main/res/layout/widget_layout.xml)
- [activity_main.xml](./app/src/main/res/layout/activity_main.xml)

## Features
- Provides a home screen widget.
- Updates widget content.
- Interacts with a companion main activity.

## Tech Stack
- Android SDK
- Java
- XML for UI layout designs
- Gradle for build management
