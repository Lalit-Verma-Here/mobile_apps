# Exercise 8: Temperature Converter

## Overview
This is the 8th exercise for the mobile application class. This android application demonstrates converting temperatures between different units.

Main Files:
- [AndroidManifest.xml](./app/src/main/AndroidManifest.xml)
- [MainActivity.java](./app/src/main/java/com/example/exp_8/MainActivity.java)
- [activity_main.xml](./app/src/main/res/layout/activity_main.xml)

## Features
- Converts temperatures (e.g., Celsius to Fahrenheit).
- Interactive user interface with input fields and buttons.

## Tech Stack
- Android SDK
- Java
- XML for UI layout designs
- Gradle for build management
